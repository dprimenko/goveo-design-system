Un icono para Negocios.

El cóctel y la bolsa son demasiado específicos: un cóctel sugiere bar, una bolsa sugiere e-commerce. La sección de Negocios incluye restaurantes, bares, tiendas, peluquerías, gimnasios… necesitamos un símbolo universal de "local físico". Estas son las mejores opciones de @phosphor-icons (la familia que ya usa Goveo en el resto de la UI).

Storefront

ph-storefront

El estándar de facto para "negocio local" en la industria: lo usan Google Business Profile, Yelp, Apple Maps, Uber Eats. Una fachada con toldo es inmediatamente legible a 16px y funciona igual para una pizzería, una boutique o una peluquería. No tiene sesgo de categoría.

Top 6 alternativas

Otras opciones sólidas.

Ordenadas por universalidad. Si Storefront no encaja con tu visual, las dos siguientes son las apuestas más seguras.

Storefront ph-storefront Universal. Toldo + puerta = "negocio". La elección segura.
Buildings ph-buildings Más urbano y abstracto. Sugiere "muchos locales en una zona".
Map Pin Area ph-map-pin-area Refuerza el ADN "geolocalizado" de Goveo. Sin sesgo de tipo de negocio.
Storefront Bold ph-bold ph-storefront Misma forma, más presencia. Útil en bottom-bars pequeñas.
House Line ph-house-line "Lugares" en sentido amplio. Más cálido, menos comercial.
Tag ph-tag Enfatiza "oferta / promoción local". Si la sección va más por descuentos.

El cambio

Antes y después.

Martini ph-martini Solo bares. Excluye tiendas, peluquerías, gimnasios.
Shopping Bag ph-shopping-bag Solo retail. Excluye restaurantes y servicios.
Storefront ph-storefront Incluye todos los tipos de negocio físico. Universal.

Implementación

Cómo lo añades.

Funciona idéntico en Astro, React y React Native.

// Astro / HTML — vía CDN (ya está cargado en este preview)
<link rel="stylesheet" href="https://unpkg.com/@phosphor-icons/web@2.1.1/src/regular/style.css"/>

<i class="ph ph-storefront"></i>             // regular
<i class="ph-fill ph-storefront"></i>        // activo / fill
<i class="ph-bold ph-storefront"></i>        // botón / pill
// React (web) — paquete oficial
npm install @phosphor-icons/react

import { Storefront } from "@phosphor-icons/react";

<Storefront size={24} weight="regular" />
<Storefront size={28} weight="fill" color="#e98027" />
// React Native — paquete oficial
npm install phosphor-react-native react-native-svg

import { Storefront } from "phosphor-react-native";

<Storefront size={24} weight="regular" color={tokens.light.fg} />
<Storefront size={24} weight="fill"    color={tokens.colors.primary[500]} />
