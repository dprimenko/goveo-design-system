Goveo Design System · Export Guide

Llévate el sistema a cualquier proyecto.

Un único paquete de tokens — colores, tipografía, espaciado, radios, sombras — que funciona en Astro, en React Native y en cualquier herramienta que entienda JSON. Copia los archivos, sigue tres pasos y empieza a construir con la misma marca.

¿Qué descargas?

Un paquete, cinco formatos.

Todos los archivos comparten el mismo tokens.json como fuente de verdad. Elige el formato que mejor encaja con tu stack:

⌐ JSON tokens.json Fuente de verdad. Compatible con Style Dictionary, Tokens Studio, scripts custom. ⌐ CSS tokens.css Variables CSS + utility classes (.gv-poster-xl, .gv-dark…). Para Astro y cualquier web. ⌐ TS tokens.ts Objeto tipado en TypeScript. React Native, React, Astro islands. ⌐ JS tokens.js JS plano sin tipos, para proyectos sin TypeScript. ⌐ PRESET tailwind.preset.js Preset listo para inyectar en tu tailwind.config.mjs. ⌐ DOCS README.md Esta misma guía en Markdown, para que viva junto al código.
export/ ├── tokens.json ← Source of truth ├── tokens.css ← CSS variables + utilidades ├── tokens.ts ← TypeScript ├── tokens.js ← Plain JS ├── tailwind.preset.js ← Tailwind preset ├── README.md ├── astro/ │ └── landing-example.astro └── react-native/ ├── theme.ts ← Provider + useTheme() └── components.example.tsx

Cómo empezar

Elige tu stack.

Pestañas con instrucciones paso a paso para cada destino.

1

Copia el archivo de tokens

Cópialo a tu carpeta de estilos. Es un único archivo CSS sin dependencias.

# desde la raíz del export
cp export/tokens.css apps/web/src/styles/tokens.css
2

Impórtalo en tu layout raíz

Una sola vez. Las variables y utilidades estarán disponibles en toda la app.

// src/layouts/Layout.astro
---
import '../styles/tokens.css';
---
3

Usa las variables en cualquier componente

Acceso directo a los tokens semánticos (--bg, --fg, --accent) o crudos (--primary-500, --space-24).

<div class="card">...</div>

<style>
  .card {
    background: var(--bg-elevated);
    color: var(--fg);
    border-radius: var(--radius-16);
    padding: var(--space-24);
    box-shadow: var(--shadow-app);
  }
</style>
4

Para la landing dark, añade .gv-dark

Aplica todo el surface oscuro + tipografía poster con utilidades listas.

<body class="gv-dark">
  <h1 class="gv-poster-xl">
    Geolocaliza <span style="color:var(--landing-accent)">tu mejor reel</span>
  </h1>
</body>
1

Añade Tailwind a Astro

Salta este paso si ya lo tienes.

npx astro add tailwind
2

Copia el preset

cp export/tailwind.preset.js apps/web/goveo.preset.js
3

Inyéctalo en tu tailwind.config.mjs

import goveo from './goveo.preset.js';

export default {
  presets: [goveo],
  content: ['./src/**/*.{astro,tsx,ts,jsx,js,md,mdx}'],
};
4

Usa las utilities

Toda la paleta y el tipo scale como clases nativas de Tailwind.

<h1 class="font-sans italic font-black uppercase tracking-tighter
           text-display1 text-white leading-none">
  Geolocaliza
  <span class="text-naranja-goveo">tu mejor reel</span>
</h1>

<button class="bg-primary-500 hover:bg-primary-700 text-white
                rounded-card-xl px-32 py-16 shadow-orange-cta">
  Empieza Gratis
</button>
1

Copia tokens + theme

mkdir -p apps/mobile/src/theme
cp export/tokens.ts                 apps/mobile/src/theme/tokens.ts
cp export/react-native/theme.ts     apps/mobile/src/theme/index.ts
2

Instala expo-font y los TTF de Inter

RN no aplica fontStyle:'italic' ni fontWeight:'900' de forma fiable en Android, así que cargamos cada combinación como una familia independiente. Descarga los TTF desde rsms.me/inter.

npx expo install expo-font
3

Carga las fuentes al arrancar

import * as Font from 'expo-font';
import { useEffect, useState } from 'react';

export default function App() {
  const [ready, setReady] = useState(false);
  useEffect(() => {
    Font.loadAsync({
      'Inter':             require('./assets/fonts/Inter-Regular.ttf'),
      'Inter-Medium':      require('./assets/fonts/Inter-Medium.ttf'),
      'Inter-Semibold':    require('./assets/fonts/Inter-SemiBold.ttf'),
      'Inter-Bold':        require('./assets/fonts/Inter-Bold.ttf'),
      'Inter-Black':       require('./assets/fonts/Inter-Black.ttf'),
      'Inter-BlackItalic': require('./assets/fonts/Inter-BlackItalic.ttf'),
    }).then(() => setReady(true));
  }, []);
  if (!ready) return null;
  return <YourApp />;
}
4

Construye con tokens

Todos los valores numéricos están en dp/px, listos para StyleSheet.

import { StyleSheet, View, Text, Pressable } from 'react-native';
import { tokens }   from './src/theme/tokens';
import { textStyles, elevate } from './src/theme';

export function PrimaryCTA({ label, onPress }) {
  return (
    <Pressable onPress={onPress} style={s.btn}>
      <Text style={s.label}>{label}</Text>
    </Pressable>
  );
}

const s = StyleSheet.create({
  btn: {
    backgroundColor: tokens.colors.primary[500],
    paddingVertical: tokens.space[16],
    paddingHorizontal: tokens.space[24],
    borderRadius: tokens.radius[16],
    ...elevate('orangeCta'),
  },
  label: {
    ...textStyles.heading,
    color: tokens.light.fgOnPrimary,
    fontFamily: 'Inter-Black',
    fontStyle: 'italic',
    textTransform: 'uppercase',
  },
});
5

Cambia el surface con ThemeProvider

Alterna entre light (chrome de app), dark (modo oscuro in-app) y landing (marketing) sin tocar componentes.

import { ThemeProvider, buildTheme, useTheme } from './src/theme';

<ThemeProvider value={buildTheme('landing')}>
  <YourScreen />
</ThemeProvider>

// dentro de cualquier componente:
const { semantic } = useTheme();
// semantic.bg, semantic.accent, semantic.fg…
1

Style Dictionary

El archivo tokens.json está estructurado para servir como entrada a Style Dictionary y generar formatos adicionales (iOS, Android, Flutter…).

// sd.config.js
module.exports = {
  source: ['export/tokens.json'],
  platforms: {
    ios:     { transformGroup: 'ios',     buildPath: 'build/ios/',     files: [...] },
    android: { transformGroup: 'android', buildPath: 'build/android/', files: [...] },
  },
};
2

Figma (Tokens Studio)

Importa tokens.json directamente desde el plugin Tokens Studio for Figma (File → Import → JSON). La estructura ya respeta el formato W3C-compatible.

3

Next.js / Vite / cualquier bundler

Misma receta que Astro: importa tokens.css en tu entry y/o usa tokens.ts donde necesites tokens en JS.

// app/layout.tsx (Next.js App Router)
import './tokens.css';
import { tokens } from './tokens';

Antes de empezar

Reglas no-negociables.

Si las respetas, tu pantalla parece Goveo. Si no, parece otra cosa.

01

App y landing, nunca juntos

La marca tiene dos voces: chrome calmado y poster italianizado. Elige una por pantalla.

02

Naranja solo en acentos

1-2 palabras de un titular, CTAs y bullets ✔ ★ ⚡. Nunca en cuerpos de texto.

03

Fondos: blanco o casi-negro

#ffffff o #09090b. Sin medios tonos, sin gradientes decorativos.

04

Solo Inter

No mezcles familias. Las voces vienen del peso (400-900) y de italic/uppercase, no de otro tipo.

05

Radios por surface

App 8-16 px. Landing 48-64 px. Si dudas, app más cuadrado, landing más blando.

06

Hit targets ≥ 44

Móvil y web. Las chips/pills suelen necesitar padding extra para llegar.
